# 🏥 Medicare – Hospital Management System

Medicare is a responsive hospital management system website developed to provide a simple and user-friendly interface for managing and accessing different hospital services.

## 🚀 Features

* 🏠 Home page
* 👨‍⚕️ Doctors section
* 🧑‍🤝‍🧑 Patient management
* 📅 Appointment booking
* 📋 Appointment history
* 🏥 Hospital departments
* 💊 Pharmacy section
* 🧪 Laboratory section
* 📁 Medical records
* 💳 Billing section
* 📞 Contact Us section
* 📱 Responsive design
* 🎨 Dynamic background changes between sections
* ✅ Appointment booking confirmation
* 💾 Appointment history using JavaScript/local storage

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Local Storage

## 💻 Main Modules

### 👨‍⚕️ Doctors

Displays information about doctors and their medical specializations.

### 📅 Appointments

Patients can enter their details, select a doctor, choose a date and time, and provide a reason for the appointment.

### 📋 Appointment History

Previously booked appointments can be displayed through the appointment history section.

### 🏥 Departments

Provides information about the different medical departments available in the hospital.

### 💊 Pharmacy

Provides information about medicines and pharmacy-related services.

### 🧪 Laboratory

Contains information about laboratory and diagnostic services.

### 📁 Medical Records

Provides a dedicated interface for accessing medical-record-related information.

### 💳 Billing

Provides a section for hospital billing and payment-related information.

## 🎯 Project Objective

The objective of this project is to design and develop a modern hospital management interface that demonstrates front-end development skills, JavaScript functionality, DOM manipulation, form handling, and responsive web design.
